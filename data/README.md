# Course data contracts

The course uses one frozen bundle with five top-level directories: `camera_traps`, `cfpb`, `dynasent`, `nhanes`, and `designed_eval`. A top-level `manifest.json` records source versions, licenses, hashes, row counts, construction decisions, and the random seed.

`data/smoke/` is a deterministic synthetic fixture generated by `scripts/build_smoke_data.py`. It exists only to test notebooks, helpers, and grading infrastructure. It must never be described to students as Caltech Camera Traps, CFPB, DynaSent, NHANES, or human-preference data.

## Student delivery from GitHub

The student release lives under `data/course/` in the public repository:

`https://github.com/skgallagher/stat-methods-ai-public/tree/main/data/course`

Generated Colab notebooks download individual files from the corresponding raw
GitHub URL. They do not require a ZIP file, Drive mount, or manual upload. Each
notebook requests only the dataset groups it uses, and cached files are reused
when their SHA-256 hashes match the public `manifest.json`.

Before publishing a release:

1. place only frozen, licensed, privacy-reviewed files under `data/course/`;
2. run `python scripts/build_course_data_manifest.py --release-id spring27-v1`;
3. verify `release_status` is `student_release` and review every listed path;
4. publish `data/course/`, `course_helpers/`, and the generated notebooks to the
   public repository;
5. run the fresh-Colab pilots against the raw GitHub URLs.

The downloader rejects any manifest not explicitly marked as a student release,
so `data/smoke/` cannot be substituted accidentally.

## Required release schemas

### `camera_traps`

- `metadata.csv`: `image_id`, `camera_id`, `sequence_id`, `frame_index`, `day_night`, `animal_present`, `image_path`
- `image_features.csv`: `image_id`, `brightness`, `edge_density`, `green_fraction`, `night_indicator`
- `model_outputs.csv`: `image_id`, `vision_prob`, `vision_pred`
- `splits.csv`: `image_id`, `split`; no camera or sequence may cross protected splits

### `cfpb`

- `complaints.csv`: ID, redacted narrative, product/issue, date, channel, consent/publication fields, similarity group, duplicate flag, source/target period
- `model_outputs.csv`: true category, fitted statistical-baseline output, cached AI output, correctness, confidence, and locked alternative-label correctness
- `future_holdout_outputs.csv`: the untouched later-period comparison rows
- `weak_analysis_plan.txt`: frozen AI-generated object for the Week 3 audit

### `dynasent`

- `items.csv` and `homework_items.csv`: disjoint lab/homework items with item ID, sentence, collection round, five-vote counts, model class probabilities and label
- `prompt_items.csv`: six homework items used for the prompt-as-measurement experiment

### `nhanes`

- `blood_pressure.csv`: participant ID, age, survey weight, and repeated systolic measurements

### `designed_eval`

- `response_pairs.csv`: pair ID, prompt family, two response texts, imperfect human-preference reference
- `order_experiment.csv`: randomized initial order, AB/BA choices, repeat consistency
- `llm_judge_prompt_variants.csv`: pair ID, protocol, judge choice, reference agreement, repeat consistency, order-reversal indicator

## Release gate

Before publishing `data/course/manifest.json` and its listed files, verify licensing/privacy, hashes, all unit/split constraints, no hidden answer leakage, visible intended effects, CPU run time, and compatibility with a fresh Colab runtime. Course-only text must be distributed through the approved CMU system rather than a public repository.
