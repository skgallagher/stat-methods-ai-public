Statistical Thinking for the AI Era

A project-centered course on evaluating AI systems with statistical reasoning: baselines, benchmarks, uncertainty, calibration, robustness, human feedback, and evidence-backed recommendations.

View final project See weekly modules

Recurring Translation

The course repeatedly connects current AI language to older statistical ideas.

benchmark→sampling design
accuracy→estimate with uncertainty
confidence→calibration question
ablation→sensitivity analysis
human feedback→measurement protocol

Course Focus

Modern AI creates new systems, scales, and interfaces. This course asks what a statistically careful person should believe after seeing AI evaluation evidence.

Start With A Baseline

Before trusting the AI system, build and understand a simple model that keeps the comparison honest.

Evaluate The Evidence

Accuracy is an estimate. Confidence needs checking. Benchmarks measure some populations and miss others.

Defend A Recommendation

Students use statistical evidence to decide whether to deploy, trust, revise, or reject an AI evaluation claim.

Syllabus Snapshot

A concise version of the course policies and expectations. The full syllabus will live in the public GitHub repo once finalized.

Format

  • Tuesday/Thursday meetings
  • Lecture plus guided lab or project studio
  • Python in Google Colab, CPU-only by default
  • AI tools permitted, but students must verify and critique their use

Assessment

  • 7 homework grades, lowest 1 dropped
  • No homework in Week 6 so students can study for the midterm
  • Closed-book, no-AI midterm in Week 7
  • Final project with checkpoints, video, oral discussion, and short report

Final Project

  • Teams of 4
  • Industry track: ShopSmart image deployment evaluation
  • Research track: Judging the Judge for LLM evaluation
  • Baseline ownership is required

Learning Goals

  • Evaluate AI benchmarks as statistical evidence
  • Quantify uncertainty or calibration in model outputs
  • Analyze robustness, ablation, and distribution shift
  • Use AI tools responsibly in statistical work

Project-First Structure

The first half builds shared tools. The second half uses structured project studios to apply those tools to image systems and LLM evaluation.
