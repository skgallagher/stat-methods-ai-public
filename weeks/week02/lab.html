4. How did the construction process change?

The word round refers to a round of dataset construction, not a second rating of the same sentences. Both rounds used the same five-person validation task, but their sentences came from different processes.

Note🔎 Context

Round 1 consists of naturally occurring Yelp sentences selected because an initial model found them challenging. In Round 2, crowdworkers edited Yelp prompts to fool a newer model trained using Round 1; five raters then validated the resulting sentences.

The 72-row teaching set has 36 items from each round and uses agreement-pattern quotas that roughly mirror the eligible pools. It is a designed teaching subset, not a simple random sample of all DynaSent sentences.

5. One forecast, two targets

Each row includes a frozen model probability vector

\[p=(p_{\text{neg}},p_{\text{neutral}},p_{\text{positive}}).\]

We score the same forecast against two different targets:

  • hard target: a one-hot vector for the majority label;
  • soft target: the three observed vote proportions.

In the class order negative, neutral, positive, write the target vector as

\[t=(t_1,t_2,t_3),\]

where \(t_k\) is the target value for class \(k\). For example, votes of \((4,1,0)\) give a negative majority label, so

\[t_{\text{hard}}=(1,0,0)\]

and

\[t_{\text{soft}}=(0.8,0.2,0).\]

For either choice of \(t\), the unnormalized three-class Brier score is

\[B(p,t)=\sum_{k=1}^3(p_k-t_k)^2.\]

The notebook creates the columns hard_brier and soft_brier at the point where this formula is applied. Scikit-learn’s label_binarize constructs the hard target. We calculate the score directly because support for multiclass Brier scoring varies across scikit-learn versions, and the soft target is a vector of empirical proportions rather than one observed class.

Inspect one sentence whose two scores differ substantially. Explain what the majority target discards and why a lower soft-target score does not prove that the soft target is universally correct.

6. What assumptions would justify averaging raters?

Before asking whether measurements are independent, name the random experiment:

  • For one fixed sentence, condition on \(X=x\) and ask how raters were assigned.
  • Across random sentences, draw one \(X\) and give that shared item to every forecaster. Their response tendencies may move together across \(X\); sharing \(X\) makes this possible, not automatic.

The law of total covariance keeps the questions separate:

\[ \operatorname{Cov}(A,B) =E[\operatorname{Cov}(A,B\mid X)] +\operatorname{Cov}(E[A\mid X],E[B\mid X]). \]

The first term is within-sentence association. The second is association across sentences. Either can be zero while the other is not.

Exchangeability is a different question: would swapping two rater identities leave the response model unchanged?

Note🔎 Worked case

For a fixed sentence, an expert and four novices may work independently. They are not exchangeable across all five if expertise changes response probabilities, though the four novices might be exchangeable among themselves.
