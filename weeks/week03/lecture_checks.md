# Week 3 lecture checks — individual, no AI

## After Lecture A

1. A help-desk model predicts the queue recorded by a staff member. Name one
   larger claim that high accuracy would **not** prove.

2. Put the two comparisons in the correct order:
   
   A. complex model versus simple model  
   B. simple model versus a rule that ignores the text

3. Match each question to a split:
   
   - performance on requests received next semester;
   - performance for people not represented in training;
   - performance on another request from the current mixture.
   
   Choices: random rows · time split · people held out

4. Which data should choose a model setting: training, validation, or test?
   Why should the test result not be used for that choice?

## After Lecture B

5. An analyst learns the TF-IDF vocabulary from all requests before splitting
   them. State exactly what information moved in the wrong direction and how
   fitting the pipeline on training data keeps that information out.

6. A time split contains no rows from the future in training, but three
   `similarity_group` values appear in both training and test. What does each
   check tell you? Why do we need both?

7. **Transfer check:** Give one way a detailed AI prompt can improve an analysis
   because it supplies a missing study decision—not merely because the prose is
   clearer.
